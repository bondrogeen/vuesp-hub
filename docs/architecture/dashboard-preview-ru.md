# Панель управления (превью)

Экспериментальная страница `/dashboard-preview/` в Vuesp Hub — конструктор
плиток на [GridStack](https://gridstackjs.com/). Она нужна, чтобы проверить,
как может выглядеть будущая настраиваемая панель устройств.

## Что умеет

- добавлять плитки разных типов через диалог;
- перетаскивать и менять размер карточек;
- группировать плитки: перетащите карточку внутрь группы, она станет частью
  вложенной сетки (GridStack sub-grid);
- блокировать раскладку от случайных изменений;
- сбрасывать раскладку к демонстрационной;
- сохранять раскладку в `localStorage` (`vuesp.hub.dashboardPreview.v1`).

## Типы плиток

| Тип | Что показывает |
| --- | --- |
| Датчик | температура, влажность, CO₂, мощность |
| Камера | демо-поток, время, статус LIVE |
| График | столбцы динамики показателя |
| Свет | вкл/выкл и яркость |
| Климат | целевая температура и кнопки ± |
| Медиа | обложка, воспроизведение, прогресс |
| Группа | контейнер с вложенной сеткой |

## Данные

Пока это демо-данные: значения обновляются раз в 2,5 секунды. Камера — заглушка
с анимацией, а не реальный поток.

Следующий шаг — подключить реальные источники:

- камеры через модуль `vuesp-hub.video.cameras` и `useCameraStream`;
- значения плиток из `WebSocketStore` и `mains`;
- управление устройствами через `onSetState` и `buildTileCommands`.

## Сохранение

После перетаскивания, изменения размера, добавления или удаления плитки
раскладка сохраняется автоматически. При загрузке страницы она
восстанавливается, включая вложенные группы. Сброс очищает `localStorage` и
возвращает демо-раскладку.

## Ограничения

- это превью, а не рабочая панель: данные демонстрационные;
- раскладка хранится только в браузере, между устройствами не синхронизируется;
- нет прав доступа: страница доступна всем авторизованным пользователям хаба;
- на очень узких экранах сетка остаётся 12-колоночной, карточки становятся
  мелкими — адаптивные колонки нужно продумать отдельно;
- группировка работает перетаскиванием в контейнер, отдельного мультивыбора
  плиток нет.

## Сборка

```bash
cd vuesp-hub
npm run build:hub
```

После пересборки перезапустите хаб и откройте `/dashboard-preview/`.
